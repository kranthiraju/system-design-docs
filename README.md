# System Design Docs

A collection of **Excalidraw diagrams and visual notes** for learning, explaining, and revising system design concepts.

The goal of this repository is to simplify system design through clear architecture diagrams and visual explanations.

## 📌 Contents

* Core system design concepts
* Distributed systems
* Architecture patterns
* Scalability and performance
* Databases and storage
* Caching
* Load balancing
* Messaging and event-driven architecture
* Microservices
* Reliability and fault tolerance
* Real-world system design

All diagrams are created using **Excalidraw** and stored as `.excalidraw` files.

## 🎨 Usage

Open the `.excalidraw` files using **Excalidraw** to view, edit, or extend the diagrams.

## 🎯 Purpose

These diagrams are useful for:

* Learning system design
* Interview preparation
* Architecture discussions
* Technical documentation
* Quick revision
* Visualizing distributed systems

The diagrams focus on **clarity over complexity**, highlighting components, data flow, scalability, reliability, bottlenecks, and trade-offs.
